# Crypto Quant Dashboard

A dashboard for visualising crypto market data and quantitative signals, built on the Crypto Data API.

## Status

Early stage. The project structure, stack, and setup instructions will be added as development progresses.

## Planned features

- Live price and volume charts for major crypto assets
- Quantitative indicators (volatility, momentum, correlations)
- Portfolio and strategy performance views

## Getting started

Clone the repository:

```bash
git clone https://github.com/Crypto-Data-API/crypto-quant-dashboard.git
cd crypto-quant-dashboard
```

Setup and run instructions will follow once the stack is in place.
